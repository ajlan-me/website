# Journal posts

Add one Markdown file per post, named `YYYY-MM-DD-short-slug.md`, e.g.
`2026-11-06-launch-week-notes.md`. The slug in the filename becomes the URL:
`/journal/launch-week-notes/`.

Each file starts with front matter:

```markdown
---
title: What launch week taught me
description: One or two sentences that summarise the post (used by Google and link previews).
date: 2026-11-06
draft: false
---

Your post, written in Markdown.

![Alt text describing the photo](/images/ajlan-portrait-white-t-shirt-window-light.jpg)
```

Posts with `draft: true` are never published. This README is ignored by the build.
